
# NVIDIA DGX Spark Learning Workflows

A minimal, reproducible learning repo for understanding GPU containers, DGX Spark workflows, and the transition from experimentation to production in the NVIDIA ecosystem.

---

## 🎯 Purpose

- Learn GPU-enabled Docker workflows
- Understand how DGX Spark runs AI workloads
- Build reproducible container environments
- Bridge to production (e.g., Triton inference)

---

## 🧱 Stack

- Docker
- NVIDIA Container Toolkit
- CUDA-enabled base images
- PyTorch / HF / TGI (as applicable)
- NVIDIA AI Workbench (optional)

---

## 📂 Structure

learner: 1. read how-to-learn.md
      2. check reference-links
      3. use spark manual if needed

teacher: 1. read how-to-teach.md
2. use attached graphics for clarity

---

## 🧠 Key Idea

Docker ensures environment consistency.
DGX provides GPU acceleration.
Triton (later) serves models at scale.

This repo focuses on mastering the bridge from development to production-ready AI systems.
